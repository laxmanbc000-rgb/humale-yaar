# हुमाले यार

नेपाली भाषामा बोलेर फोन चलाउने AI सहायक (Android) — Kotlin + Jetpack Compose + Claude API।

## चरण १ मा के छ
- नेपाली/English आवाज सुन्ने (लाइभ टेक्स्टसहित) र आवाजमै जवाफ दिने; बोल्दा-बोल्दै माइक थिच्यो भने बोली रोकिन्छ
- फोन टुल: एप खोल्ने, कल, SMS, अलार्म, टाइमर, टर्च, भोल्युम, उज्यालो, साइलेन्ट मोड
- वेक वर्ड "हे यार" (पृष्ठभूमि सेवा)
- API key सुरक्षित (EncryptedSharedPreferences) र सेटिङ

## फोनबाटै APK बनाउने तरिका
1. GitHub मा नयाँ repo बनाउनुस्, यो फोल्डरका सबै फाइल (लुकेको `.github` फोल्डरसहित) अपलोड गर्नुस्।
2. repo को **Actions** ट्याबमा "APK बनाउने" चल्छ (वा Run workflow थिच्नुस्)।
3. सकिएपछि त्यो run खोल्नुस् → तल **Artifacts** बाट `humale-yaar-debug-apk` डाउनलोड गरेर install गर्नुस्।
4. एप खोलेर **सेटिङ** मा Claude API key हाल्नुस्।

## टिप्पणी
- उज्यालो र साइलेन्ट मोडका लागि एपले पहिलो पटक सेटिङ पेज खोल्छ — अनुमति दिनुस्।
- वेक वर्ड फोनको स्पिच रिकग्निजरमा भर पर्छ; केही फोनमा Google को "ne-NP" अफलाइन भाषा डाउनलोड गर्दा राम्रो चल्छ।
